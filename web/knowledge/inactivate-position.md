# Inactivate Position in Oracle Cloud
Job aid, last updated 7/21/25.

Purpose: inactivate a position in Oracle Cloud. Requires Oracle Cloud access with HCM permissions.

## Step 1: Open Manage Positions
1. From the home page, select the "Our Workforce" tab.
2. Click the "Workforce Structures" module.
3. Click "Manage Positions".

## Step 2: Search for the position
1. Enter in the search fields: Business Unit; Code (the position number); Effective As-of Date.
2. Click "Search".
3. Click the "Position Name" link.

## Step 3: Update the position
1. Using the "Edit" dropdown, select "Update".
2. Confirm the effective date is correct.
3. Select "Inactivate Position" in the "Action Reason" dropdown.
4. Confirm "Action Reason" is set to "Inactivate Position".
5. Select "Inactive" in the "Status" dropdown.
6. Click "Review".

## Step 4: Submit
1. Confirm the position has been updated to "Inactive".
2. Explain the reason for the update in the "Comments" section.
3. Click "Submit" at the top of the screen.
4. Confirm submission.
