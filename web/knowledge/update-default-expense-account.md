# Update Default Expense Account in Oracle Cloud
Job aid, last updated 7/1/25.

Purpose: update an employee's Default Expense Account in Oracle Cloud. Requires Oracle Cloud access with HCM permissions.

## Step 1: Open Change Assignment for the employee
Either:
1. From the Home page, search for the employee.
2. Click the drop-down arrow next to the employee's name and select "Change Assignment".

Or:
1. From the Home page, select the "Our Workforce" tab.
2. Click "Show More" under "Quick Actions" on the left-hand side.
3. Scroll to the "Employment" section and select "Change Assignment".
4. Search for the employee using the search bar or "Advanced Search".

## Step 2: Update the Default Expense Account
1. In Change Assignment, click "Continue". Do not select any options under "What info do you want to manage?".
2. Enter the assignment change start date.
3. Under "What's the way to change the assignment?", select "Change Default Expense Account".
4. Under "Why are you changing the assignment?", select "Update Default Expense Account".
5. Click "Continue".
6. Click the "Select: Default Expense Account" icon next to the Default Expense Account field.
7. Enter the correct COA (Chart of Accounts) information. All fields must be completed.
8. Click "Ok".

## Step 3: Submit
1. Confirm the correct COA has been entered.
2. Click "Submit" at the top of the screen.
3. Confirm submission.

Note: changes to the Default Expense Account are automatically approved by Oracle after submission.
