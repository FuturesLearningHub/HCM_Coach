# Update Costing for Persons in Oracle Cloud
Job aid, last updated 2/17/26.

Purpose: update costing information for an employee's assignment in Oracle Cloud. Requires Oracle Cloud access with HCM permissions.

## Step 1: Open Costing for Persons
1. From the Oracle homepage, go to the "Our Workforce" tab.
2. Select Costing for Persons from the "Quick Actions" menu.

## Step 2: Search for the employee
1. In the search bar, click Advanced Search.
2. Select OK to open the advanced search fields.
3. Enter the effective date for the updated costing and click "Ok".
4. Enter the employee's name in the Person Name field.
5. Click the Search icon.
6. In the results list, click the employee's name to open their costing details.

## Step 3: Select the assignment
1. Under "Costing for a Person Overview", find the list of assignments.
2. Click the specific assignment you need to update.
3. Open the Edit drop-down menu.
4. Select Update.

## Step 4: Update the costing information
1. Enter the Percentage (100% unless directed otherwise).
2. Enter the correct Chart of Accounts (COA) string for the assignment.

## Step 5: Submit
1. Review the costing information for accuracy.
2. Click Submit.

Note: changes to costing are automatically approved by Oracle after submission.
