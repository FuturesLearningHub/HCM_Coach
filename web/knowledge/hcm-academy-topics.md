# HCM Academy: topics covered by the program
Program outline. This lists what HCM Academy teaches. It does not contain the procedures themselves.

- Recruitment and Hiring: job architecture and how it affects recruiting; when to create a new position versus update an existing one; Direct Hire versus Recruit-to-Hire (ORC); pending worker conversions; hiring by worker type (staff, faculty, student workers, paid and unpaid interns, union employees, non-workers); when to add an assignment versus create a work relationship.
- Payroll and Timecards, Compensation Management: salary changes and individual compensation actions; compensation impacts on payroll processing; updating employee timesheets; approving timecards on behalf of managers.
- Position Management: creating positions; updating positions; best practices.
- Assignment Changes: transfers; location changes; manager changes; assignment update scenarios.
- Offboarding: voluntary and involuntary terminations; ending assignments versus terminating employment; terminations when an employee has multiple assignments; offboarding requirements.
- Leave Management: leave status updates; entering and managing FMLA/TMLA (continuous versus intermittent); differences for monthly versus biweekly employees; leave administration workflows in Oracle.
- Costing Management: costing fundamentals; how costing affects payroll and financial reporting; when and where to update costing in Oracle.
- Student and Faculty Hiring and Assignment Changes: student hiring; faculty hiring; assignment changes; Oracle transactions and approvals for these groups.
