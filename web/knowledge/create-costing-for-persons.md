# Create Costing for Persons in Oracle Cloud
Job aid, last updated 8/4/26.

Purpose: create costing for an employee's assignment in Oracle Cloud. Requires Oracle Cloud access with HCM permissions.

## Step 1: Open Costing for Persons
Either:
1. From the Home page, search for the employee.
2. Click the drop-down arrow next to the employee's name and select "Costing for Persons".

Or:
1. From the Oracle homepage, go to the "Our Workforce" tab.
2. Select Costing for Persons from the "Quick Actions" menu.
3. Search for the employee using the search bar or "Advanced Search".

## Step 2: Select the assignment
1. Under "Costing for a Person Overview", find the list of assignments.
2. Click the specific assignment you need to add costing to.
3. Click the "Actions" drop-down.
4. Select "Create", then "Create Costing".

## Step 3: Create the costing information
1. Enter the effective date.
2. Enter the Percentage (100% unless directed otherwise).
3. Enter the correct Chart of Accounts (COA) string for the assignment.

## Step 4: Submit
1. Review the costing information for accuracy.
2. Click Submit.

Note: changes to costing are automatically approved by Oracle after submission.
