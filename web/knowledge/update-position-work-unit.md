# Update Position Work Unit in Oracle Cloud
Job aid, last updated 7/10/2025.

Purpose: update the work unit on a position in Oracle Cloud. Requires Oracle Cloud access with HCM permissions.

## Step 1: Open Positions
1. From the Oracle homepage, go to the "Our Workforce" tab.
2. Select Workforce Structure from the "Apps" menu.
3. Click "Positions".
   Another way: click "Show more" under "Quick Actions" on the left-hand side, then under "Workforce Structure" click "Positions".

## Step 2: Search for the position
1. In the search bar, type the position name.
2. Review the position code associated with the position name.
3. Click the position name.

## Step 3: Update the work unit details
1. Click "Update" in the right-hand corner.
2. Change the "effective start date" to the desired date.
3. Change "Action Reason" to "Change Position Work Unit".
4. Make sure the status is set to "Active".
5. Business Unit should be set to "Information Technology".
6. Confirm the "Name of the Position" and the "Position Code".
7. Change the "Work Unit" to the updated work unit number.
8. Leave "Location & Manager" blank.
9. Confirm Work Unit Type: "Pooled" (multiple positions) or "Single" (one position).
10. Set "Term/Flex" to "N/A".
11. Leave "JCAT" blank.
12. Leave "Budget Details" blank.
13. Leave "Grade" blank.
14. Add a brief "Comment" on the reason for the change.

## Step 4: Submit
1. Review the position information for accuracy.
2. Click Submit.

Note: Oracle automatically approves changes to work units after submission.
