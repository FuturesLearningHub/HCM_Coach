# Change Employee Manager in Oracle Cloud
Job aid, last updated 3/2/26.

Purpose: change an employee's manager in Oracle Cloud. Requires Oracle Cloud access with HCM permissions.

## Step 1: Open Change Manager for the employee
Either:
1. From the Home page, search for the employee.
2. Click the drop-down arrow next to the employee's name and select "Change Manager".

Or:
1. From the Home page, select the "Our Workforce" tab.
2. Click "Show More" under "Quick Actions" on the left-hand side.
3. Scroll to the "Employment" section and select "Change Manager".
4. Search for the employee using the search bar or "Advanced Search".

## Step 2: Change the manager
1. Do not make any changes on the "Info to Include" page. Click "Continue".
2. Select the effective date in "When does the manager change start?".
   Note: the effective date must be the first day of the pay period (Sunday) for non-exempt employees.
3. Select "Manager Change" for "What's the way to change the manager?".
4. Select "Change Line Manager" for "Why are you changing the manager?".
5. Click "Continue".
6. Click the pencil icon next to the active manager assigned to the employee.
7. Delete the active manager's name and search for the new manager in the "Managers" field.
8. Click the correct manager in the list.
9. Click "Save".
10. Click "Submit".

Note: manager changes are automatically approved in Oracle. A confirmation notification is sent shortly after the change is submitted.
